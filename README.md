# tdaMCBBproject
This repository houses the data and code files for my final project for MATH 412: Topological Data Analysis at Duke University.

Disregard any repositories by a similar name, all relevant files are now uplaoded here.

The downloadshotdata.qmd file was used in R to pull shot location data from ESPN, using the hoopR package, and exported the data files into their respective folder (NBA or MBB) in the data folder.

To run the rest of the code, pull the entire repository into a virtual environment (like Jupyter), open tdabball.py and TDAbasketballNotebook.ipynb, and run the notebook. (NOTE: some cells will have long runtimes)
